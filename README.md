# NIP Movie Ticket Booking

## Project Overview
A Movie Ticket Booking Management System developed using Pega App Studio.

## Objective
The system manages the complete movie ticket booking process, from booking request and availability checking to approval, ticket execution, and final completion.

## Case Lifecycle
1. Booking Request
2. Availability
3. Approval
4. Booking Execution
5. Completion
6. Process Review

## Key Features
- Movie and show details
- Show type selection
- Ticket quantity
- Seat preference
- Ticket pricing
- Total cost
- Venue and booking status
- Availability checking
- Booking approval
- Ticket ID and seat number handling
- Premium/Regular routing
- Booking confirmation notification
- Customer email
- SLA management

## Technologies Used
- Pega App Studio
- Pega Case Management
- Pega Workflow
- Data Transforms
- Decision/Routing rules
- Notifications
- Service-Level Agreements (SLA)

## Workflow
Booking Request → Availability → Approval → Booking Execution → Completion → Process Review
